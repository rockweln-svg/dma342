WNY FLASH ACADEMY — PROJECT 2
==============================

This is a responsive, multi-page HTML/CSS/JavaScript recreation based on your six reference screenshots.

FILES
- index.html     Landing page
- news.html      News page
- signup.html    Sign-up form
- contact.html   Contact information
- store.html     Store categories
- about.html     About / mission page
- styles.css     Shared design and responsive styling
- script.js      Mobile navigation and form interaction
- assets/        Local image crops used by the pages

OPEN IN VISUAL STUDIO CODE
1. Extract the project2 folder into: dma342/project2
2. Open Visual Studio Code.
3. Choose File > Open Folder... and select dma342/project2.
4. Open index.html and use Live Server (if installed), or open index.html directly in a browser.
5. All page links use relative paths, so navigation works when the folder is moved together.

NOTES
- The sign-up form is a front-end demonstration only; it does not send registrations to a server.
- Store category cards open an email inquiry to WNY@flash.com.
- Social links are placeholders; add the academy's real social profile URLs when available.
- Google Fonts are used when internet access is available, with local system font fallbacks.
